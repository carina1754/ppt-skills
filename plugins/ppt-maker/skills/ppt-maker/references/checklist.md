# AI 티 점검표

만든 뒤 모든 장을 그림으로 떠서 본 다음 이 표를 돕니다. 걸린 항목은 고치고 그 장을 다시 봅니다.

## 내용

- [ ] 제목이 낱말("현황", "개요", "결론")이 아니라 주장 문장이다
- [ ] 제목만 이어 읽어도 이야기가 된다
- [ ] 모든 장이 글머리표 3~5개 같은 모양으로 되풀이되지 않는다
- [ ] 빈말이 없다: 혁신적인, 획기적인, 시너지, 새로운 패러다임, 원활한, 최적화된, 다양한, 효율적인, 한눈에, 차별화된
- [ ] 숫자마다 기준 시점이나 출처가 있고, 받은 자료에 있는 숫자다
- [ ] 보고, 제안서라면 결론이나 요청이 앞쪽에 있다
- [ ] 발표용이면 화면 글은 짧고 말은 발표자 노트에 있다

## 디자인

- [ ] 보라, 남색 그라데이션 배경, 유리 효과 카드가 없다
- [ ] 같은 모양 아이콘 카드 3개를 줄 세운 장이 없다
- [ ] 이모지 글머리표, 장식 아이콘이 없다
- [ ] 모든 요소에 같은 그림자, 같은 둥근 모서리를 쓰지 않았다
- [ ] 같은 배치가 세 장 넘게 이어지지 않는다
- [ ] 글꼴은 두 가지 이하이고 한글 글꼴이 목록 맨 앞에 있다
- [ ] 강조색은 한 장에 한 곳이다
- [ ] 그래프는 직접 이름표이고 강조 계열만 색이다

## 한국어

- [ ] 단어 중간에서 줄이 끊기지 않는다
- [ ] 제목이 두 줄을 넘지 않고, 마지막 줄에 한두 글자만 남지 않는다
- [ ] 한 문체로 썼다
- [ ] 가운뎃점 대신 쉼표를 썼다
- [ ] 영어 장 제목("Key Insights", "Overview")이 남아 있지 않다

## 화면

- [ ] 넘침, 겹침, 잘림이 없다(그림으로 확인)
- [ ] 회의실 뒤쪽에서 읽힐 크기와 대비다. 밝은 회색 글자가 없다
- [ ] 쪽 번호, 출처 자리가 장마다 같다
- [ ] 비어 있는 `[ ]` 칸을 사용자에게 알렸다
